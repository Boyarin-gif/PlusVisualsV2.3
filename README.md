# PvP Plus 2.1 (Fabric, Minecraft 1.21.11)

K - меню в стиле Pulse Visuals: слева настройки выбранного пункта, по центру функции (вкладки Visuals / HUD / Utils, поиск),
справа метки. Кнопка "Редактор HUD" - панели перетаскиваются мышью.
C (держать) - зум. V - открыть шалкер из инвентаря (мод нужен и на сервере).
Яркость: Utils -> Brightness (включить и выбрать силу).
Клавиши меняются в настройках управления, раздел "Прочее".

Сборка: загрузи файлы в репозиторий GitHub (папки src и .github целиком), результат - вкладка Actions -> Artifacts -> pvpplus-jar.
